# DICOM Anonymization Tool

DICOM 医学影像脱敏工具，用于对 DICOM 文件进行去标识化处理，保护患者隐私信息。

## 主要功能

- **批量处理**：支持单个文件或整个文件夹的批量脱敏
- **自定义规则**：可配置每个标签的处理方式（匿名化或删除）
- **标签查看**：查看脱敏前后的标签对比
- **双语支持**：界面支持中英文切换
- **0010组标签**：自动处理所有患者信息相关标签
- **私有标签**：支持厂商私有标签的脱敏处理

## 脱敏规则

- **匿名化**：数字变为 0，其他字符变为 *
- **删除**：完全移除该标签

## 安装使用

### 方式一：使用可执行文件（推荐）

1. 下载最新版本的 `DICOM_Deidentify_Tool.exe`
2. 双击运行即可使用

### 方式二：从源码运行

```bash
cd dicom_deidentify_tool
pip install -r requirements.txt
python main.py
```

## 使用说明

1. **脱敏标签页**：选择输入文件/文件夹和输出文件夹，点击"开始脱敏"
2. **查看标签页**：加载 DICOM 文件查看标签信息和脱敏预览
3. **配置标签页**：设置每个标签的处理方式（匿名化/删除）
